使用向导

进入软件

打开软件需要输入管理员密码，初始密码为系统默认值。进入后可在「设置 → 修改密码」中改成自己的密码，也可在「密码保护」里关闭启动密码。

开始新的表格

在首页点击「开始新的表格」，可选择三种表格：

  • 班级量化表：输入人数和每组人数后自动分组，可填写学生姓名、每天/每周的加减分；支持自动计算、排名总结、批量加减分、加分模板、导出 Excel / PDF、趋势图和柱状图，还能增加或删除表格行。
  • 座位表：可先「导入成绩表」按成绩排座，设置每组列数后点击「生成座位表」自动排座；排座方式可选「按照成绩排」或「随机排」（好坏搭配）；点击两个座位可以手动互换；支持打印、导出图片和「保存到表格」。
  • 成绩排名表：输入学生人数和科目数即可创建，表格名称随时可改；录入姓名和各科分数后，总分和名次自动计算，并按名次从高到低自动排列（同分同名次）；科目名称可直接在表头修改；支持导入 Excel 批量填入姓名。

班级段位

首页点击「班级段位」，可录入学生每次考试成绩，系统根据进步幅度自动计算星数和段位。支持从成绩表 Excel 批量导入成绩，可查看考试记录和学生段位变化。

管理表格

首页点击「管理表格」，上方有「排名表 / 座位表 / 成绩表」三个分类标签，可对已有表格进行编辑、打印和删除。

设置

可修改密码、开关密码保护、调整点击音效和背景音乐的音量、切换中文/English、更换字体、切换界面风格。数据备份、数据云同步、检查更新也都在设置中，可在「关于软件」查看版本号和更新日志。
