# 班级服务管理系统

面向班主任的 Windows 桌面工具：班级量化表、学生名单、座位表、值日表、作业登记、成绩排名、班级段位、数据备份与自动更新。

## 下载

- 最新版本：v3.6.3
- 安装包：[GitHub Releases](https://github.com/wdwwangdawei/class-service/releases/latest)
- 支持系统：Windows 10 / 11

## v3.6.3 更新内容

- 取消旧版本遗留的默认密码（0000 / 0912），升级后启动不再被要求输入密码，也不会再被锁在启动页
- 修复锁屏状态下仍可通过侧边栏进入其他页面的问题，锁屏期间界面完全不可操作
- 密码保护仅在自行设置并开启后生效

同时包含 v3.6.2 / v3.6.1 / v3.6.0 的全部更新（默认风格、密码保护流程修复、诗意短句、作业登记覆盖更新、滚动修复、量化表下一周期、完整备份导出与校验恢复等）。

## 说明

- 所有数据仅保存在本地（`%APPDATA%\class-service-manager`），卸载不会删除
- 本软件为免费软件，仅供个人学习、班级管理使用
