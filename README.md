# 班级服务管理系统

面向班主任的 Windows 桌面工具：班级量化表、学生名单、座位表、值日表、作业登记、成绩排名、班级段位、数据备份与自动更新。

## 下载

- 最新版本：v3.8.2
- 安装包：[GitHub Releases](https://github.com/wdwwangdawei/class-service/releases/latest)
- 支持系统：Windows 10 / 11

## v3.8.2 更新内容

- 灵动岛展开面板改为 Class Daily Land 样式：240px 宽、今日课程列表、当前课程 ▶ 标记，3 秒自动收起
- 倒计时进度条改为 1px 内缩、圆角 19px，并补充头部光晕、亮点与流光扫过效果
- 收起与唤醒动画时序按 Class Daily Land 对齐：先缩为圆点停留 600ms 再上滑，滑入后 60ms 再展开
- 课程文字切换改为上下滚动动画，仅在同节课程分钟变化时触发
- 副岛在圆点/隐藏状态自动隐藏，收起时显示首字符而不是圆点

## v3.8.1 更新内容

- 灵动岛圆环尺寸、描边、配色、文字位置与间距按 Class Daily Land 实测效果对齐
- 上课前倒计时阶段灵动岛扩展为 600px 蓝色进度条，显示「下节 课程 · Ns」
- 迷你状态改为状态色圆点，全屏隐藏时先缩为圆点停留再上滑，与 Class Daily Land 一致
- 上课瞬间显示绿色「上课了！」提醒，提醒宽度与停留时长沿用灵动岛设置
- 倒计时阶段点击灵动岛不再展开面板，避免误触

同时包含 v3.8.0 / v3.7.0 / v3.6.3 / v3.6.2 / v3.6.1 / v3.6.0 的全部更新（独立置顶灵动岛与课表显示、单双周课表轮换、课程表设置、系统托盘、取消旧默认密码、锁屏防绕过、默认风格、密码保护流程修复、作业登记覆盖更新、滚动修复、量化表下一周期、完整备份导出与校验恢复等）。
