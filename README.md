# 班级服务管理系统

面向班主任的 Windows 桌面工具：班级量化表、学生名单、座位表、值日表、作业登记、成绩排名、班级段位、数据备份与自动更新。

## 下载

- 最新版本：v3.7.0
- 安装包：[GitHub Releases](https://github.com/wdwwangdawei/class-service/releases/latest)
- 支持系统：Windows 10 / 11

## v3.7.0 更新内容

- 新增顶部「灵动岛」：显示当前时间与今日作业未交、值日安排、积分榜首概览
- 点击灵动岛平滑展开详情面板，可一键进入作业登记、值日表或回到首页
- 保存、备份等操作结果会在灵动岛上短暂提示，展开 8 秒无操作自动收起
- 锁屏与密码验证期间灵动岛自动隐藏，不影响解锁流程

同时包含 v3.6.3 / v3.6.2 / v3.6.1 / v3.6.0 的全部更新（取消旧默认密码、锁屏防绕过、默认风格、密码保护流程修复、诗意短句、作业登记覆盖更新、滚动修复、量化表下一周期、完整备份导出与校验恢复等）。

## 说明

- 所有数据仅保存在本地（`%APPDATA%\class-service-manager`），卸载不会删除
- 本软件为免费软件，仅供个人学习、班级管理使用
