# 班级服务管理系统

面向班主任的 Windows 桌面工具：班级量化表、学生名单、座位表、值日表、作业登记、成绩排名、班级段位、数据备份与自动更新。

## 下载

- 最新版本：v3.8.0
- 安装包：[GitHub Releases](https://github.com/wdwwangdawei/class-service/releases/latest)
- 支持系统：Windows 10 / 11

## v3.8.0 更新内容

- 灵动岛升级为独立桌面窗口，始终置顶，收起/展开、唤醒动画、提醒条与 Class Daily Land 保持一致
- 灵动岛改为显示课表：下节课、本节剩余时间、今日无课/课程已结束，圆环随上课进度变化，不再显示作业与值日统计
- 灵动岛展开面板显示今日课程，副岛显示下节/本节课程提醒
- 新增课程表设置：提前提醒分钟数、倒计时时长、8 节课时间与周一至周日课程
- 课程表支持单双周轮换：分别设置单周与双周课程，按周自动交替，灵动岛自动显示当周课程
- 关闭主界面后灵动岛继续停留桌面，打开课件等全屏应用时自动隐藏，退出全屏后自动恢复
- 新增系统托盘：可恢复主界面、显示/隐藏灵动岛、打开灵动岛设置或退出程序
- 侧边栏「扩展」新增「灵动岛」页面，可设置顶部距离、提醒条宽度与停留、全屏隐藏、唤醒动画、副岛和动效
- 修复灵动岛设置页开关与数值修改后回读失败、看起来不生效的问题

同时包含 v3.7.0 / v3.6.3 / v3.6.2 / v3.6.1 / v3.6.0 的全部更新（顶部灵动岛、取消旧默认密码、锁屏防绕过、默认风格、密码保护流程修复、诗意短句、作业登记覆盖更新、滚动修复、量化表下一周期、完整备份导出与校验恢复等）。
