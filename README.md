# 班级服务管理系统

面向班主任的 Windows 桌面工具：班级量化表、学生名单、座位表、值日表、作业登记、成绩排名、班级段位、数据备份与自动更新。

## 下载

- 最新版本：v3.6.2
- 安装包：[GitHub Releases](https://github.com/wdwwangdawei/class-service/releases/latest)
- 支持系统：Windows 10 / 11

## v3.6.2 更新内容

- 设置新增「默认」风格，可随时恢复初始界面配色
- 修复密码保护开启/关闭状态显示与设置流程，避免未设置密码时被锁在启动页
- 首页短句更换为诗意浪漫文案
- 作业登记：同一日期同一科目重复登记时提示覆盖更新，进入页面不再残留上次未交选择，学生名单为空时不可登记

同时包含 v3.6.1 / v3.6.0 的全部更新（滚动修复、量化表下一周期、完整备份导出与校验恢复等）。

## 说明

- 所有数据仅保存在本地（`%APPDATA%\class-service-manager`），卸载不会删除
- 本软件为免费软件，仅供个人学习、班级管理使用
