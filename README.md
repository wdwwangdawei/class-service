# 班级服务管理系统

面向班主任的 Windows 桌面工具：班级量化表、学生名单、座位表、值日表、作业登记、成绩排名、班级段位、数据备份与自动更新。

## 下载

- 最新版本：v3.6.0
- 安装包：[GitHub Releases](https://github.com/wdwwangdawei/class-service/releases/latest)
- 支持系统：Windows 10 / 11

## v3.6.0 更新内容

- 量化表新增「下一周期」：基于当前表一键生成新周期表，保留姓名与分组，清空积分和排名，旧表不受影响
- 备份页新增「导出到文件夹」：一次导出全部数据（含学生名单、值日表、作业登记），可直接存到 U 盘或任意文件夹
- 备份页新增「校验并恢复」：恢复前自动校验文件并显示内容摘要，可选「合并」或「覆盖」，恢复前自动保存当前数据快照
- 备份文件不包含任何密码与同步令牌，旧版备份文件仍可直接导入
- 设置中「主题皮肤」改为「切换风格」，提供 6 款全新配色，旧风格自动切换为「晨雾蓝」
- 新安装默认无需启动密码，可在设置中自行设置并开启密码保护

同时包含 v3.5.2 / v3.5.3 的全部更新（学生名单、值日表、作业登记、首页看板、快捷加分、自动更新修复等）。

## 说明

- 所有数据仅保存在本地（`%APPDATA%\class-service-manager`），卸载不会删除
- 本软件为免费软件，仅供个人学习、班级管理使用
